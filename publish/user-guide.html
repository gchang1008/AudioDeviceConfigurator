區塊說明

① Combo
選擇 Core Audio 偵測到的活動播放裝置；視窗開啟時已預先選好 Windows 預設裝置。
② Channels
聲道數選項（2 / 4 / 6 / 8），不支援的會自動停用。

僅列出 32 kHz 至 192 kHz 之間的標準取樣率。

⑥ Active
右下角即時顯示裝置目前的實際設定；Apply 前就已讀取。
⑦ Status
目前動作的結果文字。
02 · Get started

三步上手

同資料夾需要 AudioDeviceConfigurator.exe、svcl.exe、test_audio.wav
STEP 01

啟動

雙擊 AudioDeviceConfigurator.exe，或於命令列直接執行；無參數時自動開啟 GUI。視窗預設選好 Windows 當前的預設播放裝置。

STEP 02

選設定

在三欄中點選想要的聲道、取樣率、位元深度。不支援的值會以淡灰呈現且無法選取；選錯會自動清除不相容的取樣率／位元深度組合。

STEP 03

按 Apply

按下 Apply，程式會保存原始設定、套用新設定、讀回驗證；成功後會自動循環播放 test_audio.wav，讓你立刻聽到效果。

05 · CLI

命令列模式

自動化、腳本化、無 GUI 環境適用
$ AudioDeviceConfigurator.exe --list 
{0.0.0.00000000}.{a}  喇叭 (Realtek)
{0.0.0.00000000}.{b}  喇叭 (USB Audio)
{0.0.0.00000000}.{c}  耳機 (Bluetooth)  [default]
選項說明
(no args)開啟 GUI；如偵測到 --help、--list 等則走 CLI。
--cli強制走互動式 CLI。
--list列出活動播放裝置後離開，不變更任何設定。
--device-id指定要設定的播放裝置 ID（必填完整 ID）。
--help顯示完整說明後離開。
06 · FAQ

常見問題

視窗開起來是空的，三個欄都沒有任何選項？
通常是 SVCL 沒安裝或 svcl.exe 不在同目錄。確認 svcl.exe（1.28 以上）與 test_audio.wav 都跟 AudioDeviceConfigurator.exe 在同一資料夾。
Sample Rate 怎麼只剩 32k～192k？
為了讓介面更乾淨，程式只列出最常用的 32,000 / 44,100 / 48,000 / 88,200 / 96,000 / 176,400 / 192,000 Hz。如果裝置有額外支援的低／高取樣率（例如 8 kHz 或 384 kHz），仍可透過 SVCL 命令列直接套用。
Apply 之後沒聲音怎麼辦？
先看狀態列 — 如果顯示 Switch verified; playing test audio. 表示已通過驗證，可能是其他應用程式佔用了音訊裝置；停掉其他播放程式後再點 Stop → Play 即可。如果顯示 Switch failed; original settings restored. 表示自動還原成功，可重新選擇支援的格式再試。
視窗能不能調整大小？
不能。視窗尺寸是固定設計（506 × 380，視窗大小不可調整），確保三欄並排的版面始終一致。如果需要更大尺寸的 CLI 流程或批次處理，請改用命令列模式。
Active 區跟選的設定不一樣？
這是正常現象。Active 區永遠顯示「裝置目前實際運作的設定」，不會跟著 RadioButton 即時更新；只有當 Apply 成功驗證後（或播放中斷後重新讀取），Active 才會更新成對應的值。
不支援的選項會怎樣？
裝置不支援的取樣率、位元深度會以淡灰顯示，無法被選取。如果想強制套用不支援的格式，請使用 CLI 模式並透過 SVCL 直接指定。
